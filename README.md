## 2. 命名规则

**产品名**：中文全称 + ASCII 短名。中文名进 Dock、Finder、菜单栏、关于页；ASCII 名进 `.app` 文件名、进程名、仓库名、Bundle ID、脚本。

| 产品 | 中文全称 | ASCII | 仓库 |
|---|---|---|---|
| 录屏提词器 | 刘老师 · 录课台 | `LLSStudio` | `lls-studio` |

**仓库名**：`lls-` + 短横线 + 小写英文。不用拼音缩写，不用下划线，不带年份。

**Bundle ID**：`com.liulaoshi.<ascii 短名>`，全小写无连字符。改 Bundle ID 等于换一个 App：权限、偏好、Vault 全部重来，能不改就不改。

**组织**：产品仓 `lls-projects`；技能仓与插件仓各自独立，同样收敛到 `lls-` 前缀。历史项目（`srt-craft`、`lls-lanclip`、`lls-jianclip`）保留原名，除非该产品正在整体重做。

**代码内部标识不是品牌**：目录名、文件扩展名、URL scheme、Keychain service、UTI、队列标签、类型名，这些服务于数据兼容，一律不跟着品牌改。改名的收益是零，代价是用户数据失联。

## 3. 品牌

配色只有一套：石墨黑 `#282C36 → #0D0F14`，暖光 `#FF7A5C`，内容白 `#FFFFFF`，录制红 `#FF453A`。

图形由四件事物组成，每件都对应一个真实功能，不许装饰性增删：圆角方底（App 载体）、白色卡片 + 三行横条（课件与讲稿）、圆形人像窗（出镜的人）、红点（正在录）。

文案三条：

1. 说「你」，不说「用户」。
2. 先给动作，再给结果：「打开提词器照着念，录完直接出成片」。
3. 形容词限额：一篇文案里「强大」「智能」「一站式」出现一次就够多。

## 4. 工程约束

1. **先想清楚再写**：动手前把「目标 / 现状 / 改哪几个文件 / 怎么验证」四件事说清楚。
2. **小步改**：一次提交只解决一件事。混改的 PR 一律拆开。
3. **每改必测**：受影响的面必须跑一遍。项目里有测试脚本就用它，没有就先补一个最小可跑的。
4. **发布前给证据**：构建日志、测试输出、实际截图，三者至少给两样。没有证据不算完成。
5. **不留半成品**：注释掉的代码、临时的 TODO、「先这样」的分支，提交前清干净。
6. **上游归属不删**：二次开发的项目，Apache-2.0 / MIT 的署名、NOTICE、改动声明一个不少。

## 5. 写作约束

**四项硬规则**（源自 Orwell 六条，取最常用的四条）：不用陈词滥调；能用短词不用长词；能删的字一律删；能用主动不用被动。

**六种必删句式**：

| 句式 | 为什么删 | 改成 |
|---|---|---|
| 「不是 A，而是 B」 | 800 字里出现三次就是套路 | 直接说 B |
| 结尾金句 | 与正文论证脱钩，只负责升华 | 给一条可执行的下一步 |
| 「说实话」「让我们深入探讨」 | 零信息的开场 | 直接上结论 |
| 三句同义排比 | 信息量不递进 | 留信息量最大的那一句 |
| 「具有里程碑意义」 | 删掉后句子信息不变 | 换成一次具体的数字变化 |
| 「希望对你有帮助」 | 对话残留 | 删 |

**数字优先**：能写「3 天压到 1 天半」就不写「效率显著提升」。

**事实边界**：数字、引用、人物、时间地点，有出处才写。为了让文字显得真实而编造细节，是最严重的错误。

## 6. 交付格式

**README 结构**：一句话定位 → 适合谁 → 核心功能表 → 快速开始（可直接复制执行的命令）→ 系统要求与权限 → 与上游的关系 → 改动记录。

**Commit 信息**：第一行说清「改了什么 + 为什么」，正文列影响面。中英混排时，动词用英文，名词保留原文。

**文档语言**：中文为主，技术名词保留英文原词（Bundle ID、scheme、commit、release），中英文之间留空格。

## 7. 十条自检

1. 名字对了吗？中文名与 ASCII 名各自出现在该出现的位置？
2. 图标四个元素都在？红点只有一处？
3. 老标识一个没动？（目录、扩展名、scheme、Keychain、UTI、类型名）
4. 构建过了吗？测试跑了吗？日志在哪？
5. 有没有注释掉的死代码？
6. 上游署名还在吗？
7. 文案里有没有「赋能 / 一站式 / 未来可期 / 希望对你有帮助」？
8. 每个数字都有出处吗？
9. 这篇文档里，哪一句删掉之后信息量不变？删了吗？
10. 一个没参与过的人，照着 README 能不能从零跑起来？
